# 🛒 Shopping List App

A simple Shopping List application built with **HTML, CSS, and Vanilla JavaScript** to practice CRUD operations, DOM manipulation, and browser local storage.

## ✨ Features

### 📝 CRUD Operations

- **Create:** Add new items to the shopping list.
- **Read:** Display all shopping items.
- **Update:** Edit existing items in the list.
- **Delete:** Remove items from the shopping list.

### 💾 Local Storage

- Save shopping items in the browser using `localStorage`.
- Keep items saved after refreshing the page.
- Load previously saved items when the application opens.

### ✅ Additional Features

- Input validation to prevent empty items.
- Dynamic updates using JavaScript DOM manipulation.
- Simple and user-friendly interface.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JS)
- Browser `localStorage`

## 🚀 Getting Started

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.
4. Start adding items to your shopping list!
