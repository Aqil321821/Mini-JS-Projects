# 📘 JavaScript Projects

This repository contains a collection of **vanilla JavaScript projects** built to strengthen my understanding of **core JavaScript concepts**, DOM manipulation, logic building, and modern JS practices.

The purpose of this repository is to:

- Practice JavaScript through **real projects**
- Build a **clean and structured portfolio**
- Progress from **small projects to large, production-level applications**

---

## 🧠 What This Repository Represents

- Each project focuses on **specific JavaScript concepts**
- Projects are organized in **separate folders**
- Every project has its **own README.md**
- Small & medium projects live inside this repository
- Large and complex projects are moved to **separate repositories**

---

## 🛠️ Technologies Used

- JavaScript (ES6+)
- HTML5
- CSS3
- DOM Manipulation
- Browser APIs
- LocalStorage
- Fetch API
